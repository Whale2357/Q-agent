- `git diff --check` 통과. CI에 위 검사와 두 Docker 이미지 빌드 추가.

## 운영 환경에서 반드시 남는 확인

1. 로컬에 Docker가 없어 **실제 컨테이너 빌드·실행은 미검증**. CI 또는 배포 전 빌드 환경에서 확인.
2. 실 API 키로 유료 추론/전사를 호출하지 않았으며 실제 마이크 캡처도 하지 않았음.
   운영 키·모델 권한, 실 회의 샘플 품질·지연·비용, 브라우저 마이크/WSS 왕복은 배포 환경에서 검증.
3. HTTPS/WSS 인증서·리버스 프록시, 영구 볼륨, 백업, 공개 앱 속도 제한/비용 한도는 호스팅 설정 필요.
4. 멀티 replica/worker, 무중단 세션 복구, 사용자 로그인, 서버 기록 삭제 UI는 구현 범위에 추가하지 않음.
   현 구조는 단일 realtime 프로세스용이며 재시작 시 진행 중인 녹음 세션은 끊김.
5. 테스트 통과는 모든 버그 부재나 모델 질문 품질을 보증하지 않음. 실제 회의 평가 데이터가 없어
   사람 평가 기반 품질 개선율·성능 SLA는 측정하지 않았음. 장시간/다중 사용자 부하 테스트 별도 필요.
